# Языковая модель на WikiText-2: LSTM vs GRU vs distilgpt2

Проект по курсу «Нейронные сети и обработка текста». Цель — реализовать и сравнить три подхода к задаче предсказания следующего слова на датасете WikiText-2:

- **LSTM** — рекуррентная модель, обученная с нуля
- **GRU** — упрощённая альтернатива LSTM, тот же процесс обучения
- **distilgpt2** — предобученный трансформер (оценка без дообучения)

## Описание этапов

### Этап 0. Подготовка
Импорты, фиксация `seed = 42` для воспроизводимости, загрузка датасета WikiText-2 через библиотеку `datasets`.

### Этап 1. Данные
- **EDA**: примеры текстов, статистики по строкам и предложениям, распределения длин, топ-20 слов.
- **Токенизация**: пословный словарь на train-выборке с порогом по частоте (`MIN_FREQ = 3`), спецтокены `<PAD>` и `<UNK>`.
- **Датасет**: скользящее окно длиной `seq_len = 32`; вход — первые 31 токен окна, таргет — те же токены, сдвинутые на 1 вправо.
- **DataLoader**: train / val / test.

### Этап 2. LSTM-модель
Архитектура: `Embedding → LSTM (2 слоя) → Dropout → Linear`.

Обучение с:
- оптимизатор Adam, `lr = 0.001`
- `gradient clipping` (`clip = 5.0`) для стабилизации
- метрика качества — **perplexity** (`PPL = exp(CrossEntropyLoss)`)

По итогу строятся графики Train/Val Loss и Val Perplexity.

### Этап 3. Эксперимент: GRU vs LSTM
GRU обучается с теми же гиперпараметрами. Сравнение:

| Метрика | LSTM | GRU |
|---|---:|---:|
| Параметров | 12 018 840 | 11 788 440 |
| Лучший Val PPL | ~435 | ~355 |
| Среднее время эпохи | ~106 с | ~133 с |

Веса лучшей модели сохраняются в папку `weights/`.

### Этап 4. distilgpt2
Загружается предобученная модель `distilgpt2` из библиотеки `transformers`. Вычисляется perplexity на тестовой выборке. Генерируются примеры продолжений текста.

### Этап 5. Сравнение и выводы
- Сводная таблица всех моделей (параметры, val PPL, test PPL, время).
- Топ-5 предсказаний следующего токена на 7 одинаковых контекстах для всех трёх моделей.
- График val PPL по эпохам с горизонтальной линией distilgpt2.
